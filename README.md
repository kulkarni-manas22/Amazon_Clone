# Amazon Clone

A responsive Amazon homepage clone built using HTML and CSS. This project recreates the look and feel of Amazon's landing page, including the navigation bar, search functionality UI, product showcase sections, promotional banners, and footer.

## 🚀 Features

- Amazon-style navigation bar
- Search bar with category selector
- Delivery location section
- Language selection dropdown
- Account & Orders section
- Shopping cart icon
- Promotional hero banner
- Product showcase cards
- Responsive flexbox layout
- Multi-section footer
- Font Awesome icons integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

2. Open the project folder.

3. Open `amazon-clone.html` in your browser.

No installation or dependencies are required.
